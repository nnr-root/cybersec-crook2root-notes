# 🪟 Windows

> [!abstract] Sub-index of [[OS Internals]]
> A complete Windows curriculum from NT first principles through memory, drivers, identity, enterprise domains, telemetry, debugging, and evidence-driven operations.

## 🗺️ Zero-to-Mastery Learning Path

1. [[Windows Architecture and Kernel|Windows Architecture & Kernel]] — establish the NT Kernel, HAL, Executive, objects, syscalls, scheduling, and IPC model.
2. [[Windows Memory Internals & Exploit Mitigations]] — master virtual memory, VADs, sections, heaps, pools, page faults, and exploit resistance.
3. [[Windows Drivers I-O & Kernel Debugging]] — follow IRPs through device stacks, frameworks, minifilters, interrupts, and kernel debugging.
4. [[Windows Processes Services and Boot|Windows Processes, Services & Boot]] — trace firmware through BCD, Trusted Boot, SMSS, sessions, services, tasks, and DLL loading.
5. [[Windows File System and Registry|Windows File System & Registry]] — understand NTFS metadata, ReFS, journals, hives, control sets, and forensic limits.
6. [[Windows Networking Internals]] — trace Winsock, AFD, WFP, TCP/IP, NDIS, firewall, enterprise protocols, IPv6, IPsec, and virtual networks.
7. [[Windows Security and Access Control|Windows Security & Access Control]] — calculate authorization from SIDs, tokens, privileges, integrity, SDDL, ACLs, and handles.
8. [[Windows Identity Credentials & Authentication]] — follow LSA, LSASS, SAM, DPAPI, Kerberos, NTLM, Windows Hello, and Credential Guard.
9. [[Windows Active Directory and Domains|Windows Active Directory & Domains]] — scale identity into forests, replication, trusts, DNS, LDAP, SMB, delegation, GPO, and tiering.
10. [[Windows Command Prompt & Batch]] — master `cmd.exe` parsing, expansion, batch control flow, native utilities, and the injection classes they create.
11. [[Windows PowerShell]] — automate with the object pipeline, advanced functions, CIM, WinRM remoting, JEA, and the real trust and telemetry stack.
12. [[Windows Logging and Auditing|Windows Logging & Auditing]] — engineer Event Log, ETW, audit policy, Sysmon, forwarding, retention, and correlation.
13. [[Windows Diagnostics Crash Dumps & Performance]] — diagnose crashes, hangs, memory pressure, latency, and performance with dumps, symbols, PerfMon, WPR, and WPA.
14. [[Windows Sysinternals and Troubleshooting|Windows Sysinternals & Troubleshooting]] — combine live process, file, Registry, persistence, network, memory, and signature evidence.

## Curriculum Outcome

Completion means being able to trace one Windows action from a user or network request through identity, object authorization, system-call transition, Executive manager, driver or service, storage/network effect, telemetry, and debugger evidence—then explain both the cybersecurity consequence and the root-cause correction.
